# Forever Updates assets

Images used by the "Forever Updates" WoW: Forever newsletter email.

- `icons/` – round HD class icons (shaman, warlock, druid), copied from
  [brutaliccus/ClassicWoWClassIcons_Circle_HighRes](https://github.com/brutaliccus/ClassicWoWClassIcons_Circle_HighRes).
  Class art © Blizzard Entertainment; used for a personal, non-commercial newsletter.
- `header/` – newsletter header banner (`header.png`, 1200px wide, shown at 640px).

Files are hotlinked from `raw.githubusercontent.com`, so this repo must stay public
and file names must not change.
